# Camilo Osorio — Plataforma personal v2

## Concepto
Esta versión deja de tratar el sitio como una hoja de vida y lo convierte en una plataforma editorial/profesional centrada en proyectos, ideas, academia y trayectoria.

Paleta principal:
- Negro: #08080c
- Blanco: #fafafa
- Morado: #7c3aed
- Violeta de acento: #9b5cff
- Gris/lila de soporte: #f0eef4

## Estructura
1. Home / posicionamiento
2. Perspectiva
3. Proyectos periodísticos y académicos
4. Ideas / investigación
5. Academia
6. Trayectoria
7. Reconocimientos
8. Contacto

## Archivos
- index.html
- styles.css
- script.js
- assets/camilo-osorio.jpeg

## Producción
Es un sitio estático: no necesita Node, base de datos ni compilación.
Sube todos los archivos conservando la carpeta `assets/`.

## Personalización
- Cambia enlaces o textos directamente en `index.html`.
- La foto suministrada por el usuario está incluida como `assets/camilo-osorio.jpeg`.
- El enlace de LinkedIn está configurado a: https://www.linkedin.com/in/camilo-osorio-s/
- Los proyectos y enlaces fueron tomados del documento de proyectos suministrado.
- La información académica y profesional procede de la hoja de vida suministrada.

## Próxima evolución recomendada
Para convertirla en una plataforma de publicación, se puede separar el contenido de proyectos/artículos de la interfaz y crear una pequeña estructura CMS o una versión basada en Astro/Next.js, manteniendo este diseño visual.
